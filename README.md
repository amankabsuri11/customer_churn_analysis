📊 Customer Shopping Behavior Analysis
🔍 Overview

This project focuses on analyzing customer shopping behavior using transactional data.
The goal is to understand purchasing patterns, customer segments, subscription behavior, and revenue drivers to support data-driven business decisions.

The project follows an end-to-end data analytics workflow, including data cleaning, exploratory analysis, SQL-based business queries, dashboard creation, and reporting.

📂 Dataset

Records: 3,900 customer transactions

Features: 18 columns

Data Includes:

Customer demographics (age, gender, location, subscription status)

Purchase details (product, category, amount, season)

Shopping behavior (discounts, reviews, shipping type, purchase frequency)

Missing Values:

Review ratings contained missing values and were handled during preprocessing

🛠 Tools & Technologies

Python (Pandas, NumPy) – Data cleaning & EDA

SQL (PostgreSQL / MySQL) – Business analysis queries

Power BI – Interactive dashboard & visualizations

Jupyter Notebook – Analysis workflow

Excel – Supporting analysis

🧪 Steps Performed

Loaded and explored the dataset using Python

Cleaned data and handled missing values

Standardized column names for consistency

Performed exploratory data analysis (EDA)

Engineered new features such as age groups and purchase frequency

Loaded cleaned data into PostgreSQL

Ran SQL queries to answer business questions

Built an interactive Power BI dashboard

Created a final analytical report with insights and recommendations

📊 Dashboard

An interactive Power BI dashboard was created to visualize:

Number of customers and average purchase amount

Subscription distribution

Revenue by product category and age group

Sales trends and customer behavior

📌 Dashboard screenshots are included in the repository.

📈 Results & Insights

Loyal customers contribute the majority of transactions

Express shipping users show slightly higher spending

Certain products are highly discount-dependent

Subscribers show consistent spending behavior

Young adults and middle-aged customers generate the highest revenue
